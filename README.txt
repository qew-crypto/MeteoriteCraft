MeteoriteCraft — Fabric 1.21.4 (исходный код мода)
==================================================

Это ИСХОДНИК Gradle-проекта, а не готовый .jar.
В песочнице, где я работаю, нет ни javac, ни Gradle, ни доступа в интернет,
поэтому собрать .jar я физически не могу. Сборка занимает 2 минуты у тебя:

СБОРКА (вариант 1 — проще всего)
--------------------------------
1. Скачай и распакуй архив.
2. Открой папку MeteoriteCraft в IntelliJ IDEA (File → Open → выбрать папку).
3. IDEA сама скачает Gradle и зависимости. Дождись индексации.
4. Справа вкладка Gradle → Tasks → build → build.
5. Готовый jar: build/libs/meteoritecraft-1.0.0.jar

СБОРКА (вариант 2 — консоль)
----------------------------
   cd MeteoriteCraft
   gradle wrapper      (только один раз, создаёт gradlew + gradle-wrapper.jar)
   ./gradlew build     (Windows: gradlew.bat build)
Нужна Java 21+ и интернет (скачиваются маппинги Yarn и Fabric API).

УСТАНОВКА
---------
- Fabric Loader 0.16.9+ для Minecraft 1.21.4
- Fabric API 0.110.5+1.21.4 (обязательно!) → в папку mods
- meteoritecraft-1.0.0.jar → в папку mods

КОМАНДЫ
-------
/meteor                      открыть меню (кликабельное)
/meteor menu                 то же самое
/meteor spawn                случайный метеорит в радиусе 2000 блоков, координаты в чат
/meteor spawn common         обычный метеорит
/meteor spawn rare           редкий
/meteor spawn epic           эпический
/meteor spawn legendary      легендарный
/meteor near [расстояние]    метеорит рядом (по умолчанию ~110 блоков)
/meteor here                 метеорит прямо на тебя
/meteor at                   метеорит туда, куда смотришь
/meteor locate               координаты всех активных метеоритов
/meteor clear                очистить список
/meteor kit                  выдать полный набор снаряжения
/meteor auto on | off        включить/выключить автоспавн
/meteor help                 список команд
/meteors                     алиас для меню

В меню (/meteor) всё это — кнопки: жмёшь по [Легендарный] и метеорит падает.
По координатам в чате можно кликнуть — они скопируются.

РЕДКОСТИ
--------
Обычный (белый)      — 1 сундук, простой лут
Редкий (голубой)     — 1 сундук, лут получше, часть вещей зачарована
Эпический (розовый)  — 2 сундука, много зачарованного
Легендарный (золотой)— 2 сундука, снаряжение метеорита + сильные чары

Метеорит падает с неба (видно полёт и удар), взрывается, оставляет кратер из
метеоритовых блоков и руды, а координаты пишутся в чат ТОЛЬКО после того, как
сундук реально поставлен — так что «написал, но ничего нет» больше не будет.
Высота удара определяется по реальной поверхности (heightmap), а не по числу 200.

ПРЕДМЕТЫ
--------
Посох Метеора      — ТП к ближайшему метеориту, КД 5 минут.
                     Крафт: Палка Забвения + 4 ока Эндера + 4 эндер-жемчуга
Палка Забвения     — одноразовая, вызывает метеорит туда, куда смотришь.
                     Крафт: 4 блока незерита + палка + 4 звезды Незера
Локатор Метеоритов — координаты всех метеоритов, КД 1 минута.
                     Крафт: компас + 4 алмазных блока
Броня Метеора      — настоящая броня (шлем/нагрудник/поножи/ботинки),
                     на +1 брони больше незеритовой, полный сет = огнестойкость,
                     чары работают. Падает только из метеоритов.
Кирка Метеора      — ломает мгновенно ВСЁ, включая бедрок и барьер,
                     с авто-переплавкой руды (железо → слиток и т.д.)
Меч Метеора        — 15 урона, все чары незеритового меча
Топор/Лопата/Мотыга Метеора — тот же материал
Маяк Метеоритов    — притягивает метеориты к себе
Блоки: метеоритовый блок, метеоритовая руда, заряженный метеорит
Ресурсы: осколок, слиток, ядро, космическая пыль

У каждого предмета в подсказке написано, что он делает, урон и КД.
Все предметы лежат во вкладке креатива «Метеориты» и дублируются в
стандартных вкладках (Бой, Инструменты, Ингредиенты, Блоки).
